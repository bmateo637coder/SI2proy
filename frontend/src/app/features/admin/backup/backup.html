Copias de Seguridad (Backup & Restore)

Gestione la seguridad de los datos de todo el sistema SaaS.

⚠️ Módulo Crítico: Estas acciones afectan directamente la base de datos principal de producción. Proceda con máxima precaución.

Descargar Copia de Seguridad

Genera un archivo `.sql` con el volcado completo de la base de datos (estructura y datos). Es recomendable hacer esto periódicamente o antes de restaurar un estado anterior.

⬇️

Restaurar Sistema

Restaura la base de datos a partir de un archivo `.sql`. Nota: Los datos actuales serán eliminados y sobreescritos por los del archivo.
